# ReachHUD

A lightweight Minecraft Fabric mod that displays reach information through an in-game HUD.

## Features

- Real-time reach display
- Target tracking
- Projectile trajectory prediction
- HUD toggle and notifications

## Compatibility

- Minecraft: 26.3
- Mod Loader: Fabric
- Java: 25

## Installation

1. Install Fabric Loader for Minecraft 26.3.
2. Download ReachHUD.
3. Place the `.jar` file in your Minecraft `mods` folder.
4. Launch the game.

## Controls

| Keybind | Action |
|---|---|
| Right Control | Toggle HUD |

The keybind can be changed in Minecraft's Controls settings.
